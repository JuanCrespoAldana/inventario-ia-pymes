# Gestión Inteligente de Inventarios con IA para PyMEs

Proyecto de grado — sistema de inventarios multi-sede con predicción de demanda y agentes de IA.

## Estructura del proyecto

- `backend/` — API REST y lógica de negocio (FastAPI)
- `frontend/` — Dashboard web (React + Vite)
- `ml/` — Entrenamiento y evaluación de modelos de predicción de demanda
- `agents/` — Agentes de IA para recomendaciones (CrewAI)
- `infra/` — Docker y configuración de despliegue
- `docs/` — Diagramas y decisiones de arquitectura
